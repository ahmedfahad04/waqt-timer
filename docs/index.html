Why Waqt Timer?

Phone apps know where you are. Linux panel clocks do not. This closes that gap.

⏱️

Live top-bar countdown

Current waqt with time left plus the next waqt start, updating every second.

📍

Auto location

Detected over the internet, or search any city / district — Shahbag, Sylhet, Rajshahi resolve separately.

🕌

23 calculation methods

Karachi, MWL, Egypt, Makkah, ISNA and more, with Hanafi / Shafi Asr switching. Default matches Bangladesh standard.

🚫

Forbidden & Makruh windows

Noon gap, Makruh Asr and Isha highlighted — plus Friday Jumuah and Tahajjud best-time rows.

📴

Works offline

Cached timings keep the countdown running when the API is down. Autostarts on login.

🖥️

One codebase, every desktop

GNOME, KDE, XFCE and MATE. 12h / 24h toggle included.

How it looks

Sits quietly in the top bar. One click opens the full day.

How to install

Two ways — from source (recommended) or from a .deb release.

Recommended

Option A — Run from source

Clone, install dependencies, run. Update later with git pull.

# clone the repo
git clone https://github.com/ahmedfahad04/waqt-timer.git
cd waqt-timer
# dependencies (Ubuntu/Debian)
sudo apt install python3 python3-gi gir1.2-gtk-3.0 \
  gir1.2-ayatanaappindicator3-0.1
# test, then run
python3 pkg/opt/waqt-timer/waqt_timer.py --test
python3 pkg/opt/waqt-timer/waqt_timer.py &

Option B — Install the .deb

Download waqt-timer_1.5.2_all.deb from Releases, then:

cp ~/Downloads/waqt-timer_1.5.2_all.deb /tmp/
sudo apt install /tmp/waqt-timer_1.5.2_all.deb
waqt-timer --test
waqt-timer &
  1. Launch waqt-timer from the app grid or terminal.
  2. Open Location and display from the indicator menu.
  3. Keep auto-locate on, or type a city and press Enter.
  4. Pick method + Asr school matching your local mosque.
